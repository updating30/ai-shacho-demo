# AI社長カンパニー（制作事例・見せる用）

Claude Code で、副業の受注業務（案件選び・応募文の下書き・返信の準備・受注後の要件整理・納品準備）を回している「AI社長」の紹介ページです。AIが判断材料をつくり、人が決める。毎週の業務として実際に使っています。

**紹介ページ（ブラウザで開けます）**：https://updating30.github.io/ai-shacho-demo/

このリポジトリは「見せる用」です。紹介ページだけを置いています。AI社長の規則・手順書・台帳などの中身は公開していません。

## 仕組みの要点

- **AIが準備し、人が決める**：外部への送信（応募・メッセージ・納品・見積の確定）はすべて人が行い、AIは決められた5か所で止まって指示を待つ
- **判断の基準を文書で渡す**：強み・稼働条件・受けない案件、採点の配点を Markdown に明文化し、AIの判断に一貫性を持たせる
- **業務ごとの手順書**：status / weekly / apply / reply / kickoff / deliver の6種類。普段の言葉で頼むと、決まった手順で動く
- **競争の激しさも判断に入れる**：応募が殺到している案件は倍率で減点・足切り
- **状態の記録は1か所だけ**：全案件の状態は台帳だけが持つ

## 使っている技術

Claude Code（CLAUDE.md・カスタムスラッシュコマンド）、Python、SQLite（読み取り専用の接続）、Claude API、Markdown
